# キューブへの外乱と物理ドメインのランダム化

開始位置のカリキュラムに加えて、`--disturbances`と`--domain-randomization`を指定できる。
既存の69次元状態観測・4次元行動の単一PPO方策を再開して学習する。
この方策の入力は位置・速度等の状態なので、今回のdomain randomizationは物理特性を対象にする。

## エピソードごとの物理特性

| 対象 | 基準値に対する倍率 |
| --- | --- |
| キューブの質量 | 0.8〜1.2（20〜30 g） |
| キューブの慣性 | 質量と同じ倍率（形状と整合） |
| 机・キューブ・左右指パッドの摩擦 | 各接触形状で独立に0.8〜1.2 |
| 各関節の粘性 | 独立に0.85〜1.15 |
| 各モーターの位置制御ゲイン | 独立に0.9〜1.1 |

ゲインはMuJoCoのgain/biasを同時に変更して位置制御の関係を維持する。
各resetで基準値を復元してから倍率をかけ、質量等の派生定数も更新する。倍率を累積させない。
物理パラメーターを方策の入力に直接追加しない。実際の位置・速度・接触を見て対応する。

## 位置を乱す横押し

キューブを瞬間移動させず、重心にワールド座標の水平力を加える。
方向・時刻・持続時間を試行ごとに変える。

- 机上: 「近づく」の開始後0.2〜0.4秒で、重力の1.1〜1.3倍の水平力を0.06〜0.10秒。
  25 gなら約0.27〜0.32 N。机に支持され、ロボットに触れていない間だけ加える。
  実際の移動量は摩擦と質量に依存する。
- 運搬中: 「運ぶ」の開始後0.05〜0.20秒で、0.8〜1.5 m/s²相当の水平力を0.08〜0.12秒。
  25 gなら0.020〜0.038 N。運搬中だけ加える。

各押しは1回ずつ。対象の工程が短い場合や接触条件を満たさない場合は適用されない。
離す工程と終端の静止確認には力を加えず、終了条件は従来のまま。
力は物理ステップごとに更新・解除し、resetでも消去する。
適用回数と力積（力の大きさの積分）を結果に記録する。

## 学習・検証

学習では75%のresetで指定したランダム化と外乱を使い、25%は通常の物理条件を復習する。
開始位置のカリキュラムと、前の開始範囲への並列環境割当も維持する。
検証では通常条件に加えて現在の開始範囲のランダム化＋外乱条件を必ず評価し、
その成功率も開始範囲の昇格条件とbest選択に含める。
物理条件を変更して再開した場合は、以前のbestスコアと昇格の連続回数を引き継がない。

位置のサンプリングと物理・外乱のサンプリングは乱数系列を分ける。
同じシードなら、通常条件と外乱あり条件で初期配置と目標位置をそろえて比較できる。
同じ設定とシードで再現でき、評価には実際の質量・倍率・外乱適用状況も保存する。

今回の試行学習:

```bash
uv run python src/task.py train \
  --resume outputs/pick_place_expanding \
  --domain-randomization --disturbances \
  --steps 200000 --envs 8 --learning-rate 0.00005 \
  --eval-every 50000 --eval-episodes 20 \
  --output outputs/pick_place_robust
```

現在の開始範囲と、保存された外乱・ランダム化設定でviewerを開く:

```bash
uv run python src/view.py --pick-place evaluate \
  --run outputs/pick_place_robust --episodes 10 --seed 41000 --watch
```

同じ方策を通常の物理条件で確認:

```bash
uv run python src/view.py --pick-place evaluate \
  --run outputs/pick_place_robust --episodes 10 --seed 41000 \
  --no-domain-randomization --no-disturbances --watch
```

続きの学習（設定はconfig.jsonから復元）:

```bash
uv run python src/task.py train \
  --resume outputs/pick_place_robust --output outputs/pick_place_robust \
  --steps 500000 --envs 8 --learning-rate 0.00005 \
  --eval-every 50000 --eval-episodes 20
```

追加学習前の`outputs/pick_place_expanding`も保存してある。
その方策に新条件だけ加えて表示する場合は、`--run outputs/pick_place_expanding`
に`--domain-randomization --disturbances`を付ける。

## 今回の結果

開始位置の追加学習1,001,472ステップでlevel 5に到達した
`outputs/pick_place_expanding`（累計3,004,912ステップ）から、
さらに200,704ステップ学習した。保存先は`outputs/pick_place_robust`、累計3,205,616ステップ。

最終モデルを検証とは別のシード41000〜41049、決定論的推論で評価:

| 開始範囲・条件 | 追加学習前 | 追加学習後 |
| --- | --- | --- |
| level 5、通常の物理条件 | 28/50 | 35/50 |
| level 5、物理ランダム化＋キューブへの横押し | 22/50 | 30/50 |
| level 0、通常の物理条件 | 今回未測定 | 50/50 |

同じ配置で比較した50試行の結果で、最大範囲はまだ練習が必要。
外乱ありの残る失敗20回は、時間切れ17回、目標外リリース2回、空中リリース1回。
学習中の最終検証（シード10000〜10019）では、外乱あり16/20・確率的推論15/20であり、
未知の配置での成功率はそれより低い。最終評価のシードをモデル選択や学習には使っていない。

最終評価で成功した全試行について、持ち上げ高さ6.5 cm以上、机に支持されたリリース、
終了時にロボット非接触、物体速度2 cm/s未満・角速度0.5 rad/s未満を確認した。
結果・各試行・外乱適用回数は保存先の`evaluation_*.json`、成功条件の確認は`audit.json`にある。

自動テスト28件、Ruff、Pyrightを通過。追加で、各開始段階40シードずつの計200回について、
ランダム化した初期把持と物理計算の安定性を確認した。
