# 開始位置を段階的に広げる学習

`--expand-starts`で、既存の単一PPO方策を引き継いだまま開始分布を広げる。
報酬、観測69次元、行動4次元、配置成功条件、離した後の静止確認はv5のまま。
模倣学習・固定動作による行動生成は使わない。

## 分布

座標はワールド座標。物体の初期中心高さは机上の1.5 cm。

| level | 物体X (cm) | 物体Y (cm) | 手先XYの物体からのずれ | 手先高さ (cm) |
| --- | --- | --- | --- | --- |
| 0 | 21.5〜24.5 | −1.5〜1.5 | 0 | 6.5 |
| 1 | 21.1〜24.5 | −1.9〜1.9 | 各軸±0.4 cm | 6.2〜6.8 |
| 2 | 20.7〜24.5 | −2.3〜2.3 | 各軸±0.8 cm | 5.9〜7.1 |
| 3 | 20.3〜24.5 | −2.7〜2.7 | 各軸±1.2 cm | 5.6〜7.4 |
| 4 | 19.9〜24.5 | −3.1〜3.1 | 各軸±1.6 cm | 5.3〜7.7 |
| 5 | 19.5〜24.5 | −3.5〜3.5 | 各軸±2.0 cm | 5.0〜8.0 |

物体XYは各範囲から一様にサンプル。手先は独立にずらした候補から、
X 18〜24.5 cm、Y −3.5〜10.5 cm、原点からの水平距離19.5〜24.8 cmを
満たすものを棄却法でサンプルする。到達範囲外の位置へのクリップはしない。
そのため手先のずれは、境界付近では上記の全幅を使わない。
姿勢は従来の下向き、グリッパは開いた状態で、毎回「近づく」から開始する。
高さ等は初期化後の物理計算でわずかに変化する。

目標位置は従来どおりX 18.8〜21.2 cm、Y 6.8〜9.2 cm、
物体のヨー角は±0.25 rad。目標や姿勢の範囲は今回は広げない。

## 昇格と忘却対策

8並列環境では6環境を現在のlevel、2環境をひとつ前のlevelに割り当てる。
level 0では全環境がlevel 0。1環境の場合はresetの25%で前levelを復習する。

既定で50,000ステップごとに、学習環境とは別の物理環境・固定した観測正規化統計で検証する。
現在level・前level・level 0・固定位置pickを、各々決定論的推論と確率的推論で評価する
（重複するlevelは1回だけ）。検証シードは10000から。
**全条件で決定論的成功率80%以上・確率的成功率60%以上を2回連続で満たすと、
次のresetからlevelを1つ進める。** 失敗すると連続回数をリセットする。
上限はlevel 5。段階の引き下げや失敗時の自動ロールバックは行わない。

level、昇格の連続回数、並列環境への割当はconfig.jsonに保存する。
通常の再開では拡大の有効状態とlevelも復元する。
各levelのbestと定期チェックポイントを別々に保存する。
bestは検証したrandom各範囲・両推論方式の最低成功率で選び、同点では上書きしない。
評価結果にはlevelを記録し、ファイル名にもlevel・モデルの学習数・シードを含める。

## 実行

最初の追加学習:

```bash
uv run python src/task.py train \
  --resume outputs/final/pick_place_v5_2003440 \
  --stage random --expand-starts \
  --steps 1000000 --envs 8 --eval-every 50000 --eval-episodes 25 \
  --output outputs/pick_place_expanding
```

続き（`--steps`は追加分）:

```bash
uv run python src/task.py train \
  --resume outputs/pick_place_expanding \
  --steps 500000 --envs 8 --eval-every 50000 --eval-episodes 25 \
  --output outputs/pick_place_expanding
```

保存された範囲をviewerで表示:

```bash
uv run python src/view.py --pick-place evaluate \
  --run outputs/pick_place_expanding --episodes 10 --seed 40000 --watch
```

評価時に`--start-level 0`を付ければ以前の狭い範囲、`--start-level 5`で最大範囲を指定できる。
新規学習時に`--stage`を省略すると、従来どおり把持後からのタスク段階学習を経てrandomへ進む。
`--max-start-level`で上限を指定できる。`--fixed-stage`はタスク段階の昇格を止める指定で、
明示的な`--expand-starts`による空間範囲の拡大は有効。

## 確認

各level 200シード、計1,200初期状態で、IKの成立、物体の机への支持、
ロボットと物体の非接触、有限な関節状態を確認した。
自動テストは分布の広がり、同一シードでの再現、reset境界での切替、
以前の範囲を忘れた際の昇格抑止、保存・再開でのlevel継承も検証する。


## 実施した学習

既存の累計2,003,440ステップの方策から1,001,472ステップ追加し、
level 0→1→2→3→4→5と自動昇格した。最後のlevel 5の学習は約5万ステップ。
保存先は`outputs/pick_place_expanding`、累計3,004,912ステップ。

level 5の通常条件をシード41000〜41049で最終評価した結果は28/50。
検証では進級できた範囲でも、未知の配置には失敗が残る。
その後、[外乱と物理ランダム化を加えた追加学習](domain-randomization.md)も実施した。
